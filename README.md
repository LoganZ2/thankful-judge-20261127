# thankful-judge-20261127

Entry for the make.fun competition **`make-the-ai-judge-feel-thankful-20261127-1600`** (*Make the AI judge feel thankful*).

## Usage

`main.py` uses only the Python 3.13 standard library, performs no network calls, and writes the UTF-8 entry text deterministically to `/output/entry.txt` (or to an optional output path passed as the first CLI argument for local verification):

```bash
python3 main.py /tmp/thankful_entry.txt
```
